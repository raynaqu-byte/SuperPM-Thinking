# 03 · 表达 DNA — 雷军

> 调研时间：2026-09-05 ｜ 样本：历届年度演讲全文、发布会实录、媒体观察
> 可信度：🟢基于演讲原文 🟡媒体分析 🔴推断

## 一、句式指纹

- **口语短句 + 排比铺陈**：发布会口播短促、信息密度高；讲痛点常用排比（「大家有没有遇到过……有没有……有没有……」）。🟢
- **设问推进 + 自答**：发布会高频「为什么？因为……」「你可能会问……」。🟢
- **「我们做了……」陈述主导**：汇报体与叙事体结合，像「工程师向用户汇报」。🟢
- **数据锚定句**：关键结论必配数字（「我们花了 100 亿」「续航 830 公里」「转速 27200 转」）。🟢
- **「极致」「超预期」「厚道」高频收尾**：价值句常落在这些词上。🟢

## 二、高频词与口头禅

| 高频表达 | 语境 |
|---------|------|
| 极致 / 做到极致 | 产品与做事标准（「把自己逼疯，把别人憋死」） |
| 性价比 / 价格厚道 | 价值主张 |
| 口碑 | 七字诀核心 |
| 风口 / 顺势而为 | 战略叙事 |
| 梦想 / 勇气 / 热爱 | 年度演讲情绪词（2024「勇气是人类最伟大的赞歌」） |
| 大家可能觉得 / 是不是 | 设问口头禅 |
| 我特别（不）喜欢 | 主观表态句式 |

**语言标签**：湖北仙桃口音普通话（「塑料普通话」自带辨识度与亲和力）；「Are you OK」的英语梗已成为其个人 IP 的一部分（B 站鬼畜播放数千万，他主动玩梗自嘲）。🟢🟡

## 三、节奏与转折

- **发布会式结构**：痛点铺垫 → 解决方案揭晓 → 参数轰炸 → 价格 surprise（故意停顿制造高潮）→ 上链接。
- **个人故事穿插**：年度演讲以个人奋斗史为线（武大→金山→小米→造车），用「故事→感悟→方法论」节奏推进。🟢
- **先扬后抑再扬**：常先讲困难（被质疑/至暗时刻）再转折「但我们坚持下来了」。🟢

## 四、幽默方式

- **自嘲式 + 玩梗式**：把外界嘲讽（Are you OK、雷大善人、风口猪）转化为自嘲素材，营造亲民感。🟢🟡
- 冷幽默少，更偏「憨厚式自黑」；发布会偶尔自夸后立刻自嘲找补。🟡

## 五、确定性风格

- **高度确定 + 情绪外放**：对产品/战略表态极少犹豫（「一定能成」「遥遥领先同类」由他讲出带工程师信念感）。
- 承认失败也干脆：「我错过的」「我们栽过跟头」——确定性叙事里含复盘成分。🟢

## 六、叙事与比喻习惯

- 比喻偏**奋斗/竞技意象**：长跑、爬山、高考、战场（造车如「再创业」「九死一生」）。
- 爱讲「老员工/工程师视角」故事；常提勤奋（「比谁都勤奋」人设）、自律（身材管理被媒体赞「自律即形象」）。
- 引用习惯：少引名人名言，多用自己经历与内部案例；偶尔引用行业数据。🟡

## 七、结构性沉默

- 公开表达回避：股价/资本运作细节、具体竞品贬损、重大负面事件深聊、个人生活细节。🟡🔴
