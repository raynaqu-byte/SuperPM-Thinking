## 召集规则

1. 默认全员上桌（4-9 位）；议题明确时由主持人圈定最相关 3-6 位，保证视角有张力。
2. **人物大师若未蒸馏**：用摘要卡发言，并**明确标注「摘要级，未经完整蒸馏」**，不伪装完整。
3. 每位专家先**独立**回答四问（刺眼点/怎么改/绝不会做/盲区），再进交锋 —— 顺序不可颠倒。
4. 专家只给建议，最终决策权在用户。
