# sessions（工坊产出归档）

每场工坊一个目录：`YYYY-MM-DD-主题/`，内部文件按主流程命名（见 `../工作流程.md`）：

```
00-需求输入.md          ← 阶段 0
01-需求分析.md          ← 阶段 1
02-产品规划.md          ← 阶段 2
03-专家独立评审.md      ← 阶段 3
04-交锋讨论.md          ← 阶段 4
05-最终决策.md          ← 阶段 5
06-复盘记录.md          ← 阶段 6（可选，落地后 7-30 天）
```

模板：`../templates/`。每阶段结束先落盘再进下一阶段。
