# 女娲蒸馏手册（造脑指南）

> 目标读者：想把新委员（张小龙、雷军，或任何人）蒸馏成「可用脑」的你。
> 女娲本体在 `skills/nuwa-skill/`，运行指令全在 `skills/nuwa-skill/SKILL.md` —— 本手册是它的「本地化操作指引」。

---

## 1. 女娲是什么

女娲（huashu-nuwa）**不是复制人，是提炼思维框架**。它把一个真实人物的思维方式蒸馏成一套
「可运行的认知操作系统」：

- 他用什么**心智模型**看世界？（镜片）
- 他用什么**决策启发式**做判断？（直觉规则）
- 他怎么**表达**？（DNA）
- 他**绝对不会**做什么？（反模式）
- 这个 Skill 做不到什么？（诚实边界）

关键区分：捕捉的是 **HOW they think**，不是 WHAT they said。

## 2. 开跑前的三个默认值（女娲官方建议）

| 项 | 默认 |
|----|------|
| 画像 | 全面画像（不只聚焦单维度） |
| 用途 | 思维顾问 + 产品评审委员 |
| 蒸馏档位 | 标准档（6 维度完整调研） |

> 成本提示：完整蒸馏是多 agent + 多轮搜索的长任务。**预算敏感就用「快速档」**（3 维度、
> 每维度限 5 个来源，成本约标准档 1/3），先试效果再决定是否升级。
> 换更轻量的模型跑调研可显著降低成本。

## 3. 对女娲说什么（触发词）

对已装载女娲的 AI 直接说（支持中英文触发）：

```
蒸馏张小龙。用途：产品经理思维工坊的评审委员，
重点是他的产品克制哲学与用户体验决策方式。
档位：先快速档试跑。
```

或模糊入口（让女娲先诊断推荐）：
```
我想做一个靠体验和口碑增长的产品，有没有一种思维方式能帮我判断「哪些功能不该做」？
```

女娲会自动进入 6 阶段流程：需求澄清 → 语料评估 → 采集 → 提炼 → 构建 → 质检。

## 5. 产物落点与「入会」动作

女娲的产物会写入 `.claude/skills/[person-name]-perspective/`。本项目约定：

1. 蒸馏完成后，把产物目录**复制到 `skills/personas/`**：

   ```bash
   cp -R .claude/skills/zhang-xiaolong-perspective skills/personas/
   ```

2. 用 `skills/nuwa-skill/scripts/quality_check.py` 自检产物质量（如需要）。

3. 把该委员的状态从「🕐 待蒸馏」改为「✅ 可用」：
   - 更新 `workshop/committee/zhang-xiaolong.md`（去掉「摘要级」标注，可附产物路径）
   - 更新 `workshop/committee/README.md` 名册

4. 检查产物 SKILL.md 自带的自检/保真度文件（FIDELITY.md），必要时回炉。

> 产物 Skill 必须自包含：调研文件都在 skill 目录内部，复制整个目录即可独立使用。

## 6. 常见坑

| 坑 | 应对 |
|----|------|
| 一次跑完 500k+ token，200k 窗口模型跑不完 | 女娲支持分 Phase 续跑：每 Phase 结束状态落盘到 `references/research/`，新会话从文件恢复 |
| 冷门人物公开信息 <10 条 | Phase 0.5 就会预警；接受低一档质量，或提供一手素材 |
| 人物有过系统性沉默的领域 | 忠实呈现沉默，不要替他编精巧折衷 |
| 想「蒸馏自己」做个人 PM 工作台 | 女娲有专门流程，需要你提供个人文章/备忘录/自我描述，注意自我认知偏差 |
